The project is a real - time speech emotion recognition (SER) system using deep learning and data augmentation. 
The system is trained on a RAVDESS dataset, with data augmentation tools such as noise addition and spectrogram shifting 
applied in order to increase real world robustness of the system,  
MFCCs are used to extract important features from the speech signals,
which are then provided to train a MLP neural network to classify different emotions.

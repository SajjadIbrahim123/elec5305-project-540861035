This project develops a Real-Time Speech Emotion Recognition (SER) system using deep learning and data augmentation. Trained on the RAVDESS dataset, the system incorporates data augmentation techniques—such as noise addition and pitch/time shifting—to enhance model robustness against real-world acoustic variations. Audio signals are converted into Mel-Frequency Cepstral Coefficients (MFCCs) to extract key spectral features, which are then processed by a Multi-Layer Perceptron (MLP) neural network to classify emotional states in real time.
